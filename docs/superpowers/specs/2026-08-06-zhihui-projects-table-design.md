# 智绘工程列表页重设计（门户式表格工作台）设计

日期：2026-08-06
状态：用户已确认（2026-08-06，方案 A）

## 1. 结论

将工程列表页从「卡片网格」升级为「门户式表格工作台」：保留顶部欢迎区与统计卡，主区域改为**信息密度高、可排序的表格**，每行提供操作菜单（进入/删除），空态引导增强。纯前端实现，后端零改动。

## 2. 范围

### 2.1 包含

- 表格替代卡片网格：列 = 名称 / 模式 / 状态 / 最近活跃 / 操作
- 列排序（名称 / 最近活跃；前端排序）
- 行操作菜单：进入、删除（删除弹层复用现有模式）
- 空态引导增强（无工程 / 搜索无结果）
- 保留：欢迎区、统计卡（工程总数/进行中/最近活跃）、创建区（新建/上传）、搜索
- 测试同步

### 2.2 不包含

- 后端零改动（修订数/状态前端推导；修订数不做 N+1 查询，用 currentRevisionId 推导）
- 重命名/复制（预留操作入口但点击提示「即将推出」）
- 分页（工程数量级小，前端全量渲染）

## 3. 页面结构

```
顶栏（毛玻璃）：BrandLogo 智绘 · 租户/用户名 · 退出
───────────────────────────────────────
欢迎区：{问候}，{用户} · 一句话文案
统计概览：[工程总数] [进行中] [最近活跃]（StatCard ×3）
创建区（毛玻璃大卡）：名称输入 + 新建/上传
我的工程 · [搜索框]
  ┌─────────┬──────┬────────┬────────────┬──────┐
  │ 名称     │ 模式  │ 状态    │ 最近活跃    │ 操作  │  ← 表头可排序
  ├─────────┼──────┼────────┼────────────┼──────┤
  │ 客户大屏  │ 新建  │ 进行中  │ 2 小时前    │ ⋯    │  ← 行操作菜单
  │ 设备监控  │ 上传  │ 已完成  │ 3 天前      │ ⋯    │
  └─────────┴──────┴────────┴────────────┴──────┘
空态：EmptyState（还没有工程 / 没有匹配结果）
```

## 4. 表格设计

| 列 | 内容 | 排序 |
|---|---|---|
| 名称 | 工程名（点击进入） | ✅ 字典序 |
| 模式 | StatusBadge（新建=active / 上传=info） | — |
| 状态 | 进行中（currentRevisionId 非空）/ 未开始 | — |
| 最近活跃 | relativeTime(updatedAt) | ✅ 时间序 |
| 操作 | ⋯ 菜单：进入、删除（重命名/复制预留） | — |

- 行 hover 高亮 + 名称列点击进入；行点击进入（操作区除外）
- 排序：表头点击切换 asc/desc，箭头指示
- 行操作菜单：点击 ⋯ 弹出小 popover（进入 / 删除 / 预留项置灰「即将推出」），点外部关闭

## 5. 组件

- 复用：StatCard / EmptyState / StatusBadge / SkeletonCard / BrandLogo
- 新建：`WorkspaceTable.vue`（表格本体：列定义、排序、行操作菜单）
- 删除弹层：现有列表页删除确认模式保留

## 6. 数据流与错误处理

- 纯前端：workspaces 来自 `api.listWorkspaces()`；排序/搜索/统计全 computed 推导
- 加载失败：EmptyState「加载失败」+ 重试（记入 backlog 的 I-2 本轮一并实现）
- 删除：复用现有 `api.deleteWorkspace` + 确认弹层 + 刷新
- 测试：保留现有 testid（workspace-name/create-workspace/upload-workspace/workspace-list/workspace-search/logout），新增表格/排序/菜单用例

## 7. 待办边界

- 不做重命名/复制真实功能（入口预留「即将推出」）
- 不做修订数逐工程查询（N+1 避免）
- 不做分页
