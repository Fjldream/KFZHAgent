# 参考图默认允许本轮发送

用户明确要求截图中的“我同意本轮外发”默认允许。本次只调整工作台上传后的默认值：当前租户和视觉功能允许时，单张参考图上传成功后默认勾选；点击发送才提交带图Run，不会上传后自动调用模型。

用户仍可取消勾选，取消后按钮和Enter均阻止带图发送，不会悄悄变成纯文字。新图片成功上传时重新应用默认值；上传中/失败保持未勾，移除、会话切换或刷新仍清除附件和旧同意。迟到的其他上传不能覆盖当前会话取消勾选的选择。管理员更改图片策略仍清除旧同意，不自动修改租户设置。

服务端的租户权限、视觉能力、图片审核、独立蓝图确认及现有noticeVersion不变；只改变前端默认勾选交互。本条已同步到原产品设计顶部，替代历史“默认不勾”的默认值要求。无需数据库迁移或后端重启。

验证：先用3个新用例在旧默认值上得到3项预期失败，修改后完整Web33文件236项通过；类型检查、2个变更TypeScript文件lint和Web生产构建通过。实际试用界面的浏览器测试验证默认勾选、已就绪图片可发送、取消后Enter与按钮阻止发送；上传由浏览器夹具截获，未写入附件/提交Run/调用模型，不冒充真实视觉生成验收。
