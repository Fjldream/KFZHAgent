# 工作台会话操作与图片设置修复

用户反馈：消息区出现没有样式的改名输入框/归档按钮，输入框上方常驻一整块租户图片外发说明。功能本身已接通，但这两处没有融入工作台，不能以通过流程测试替代界面验收。

| Before | After | Why |
| --- | --- | --- |
| 会话管理表单常驻消息区，浏览器默认输入框/按钮 | 标题旁“…”菜单，按需打开重命名表单或归档/恢复 | 保持消息区完整，低频操作有明确入口 |
| 租户图片外发设置常驻输入区上方 | 输入区底部“图片设置”显示状态，点击展开说明和管理员操作 | 减少常驻说明，管理员仍需明确操作 |
| 新控件未处理键盘/小屏/点击外部 | 原生details/summary、焦点返回、Escape/外部点击收起，桌面和390px小屏实测 | 保证操作可见且不遮挡或溢出屏幕 |

仅修改Agent前端。会话API、归档冲突、图片外发默认值、管理员权限及逐次图片同意不变；没有自动授权图片外发。上传后的本轮外发同意仍在附件旁，不被设置面板替代。后端、模型协议、数据库迁移、生成器和KF原生服务未修改。

验证：完整Web33文件233项通过（含新增8项菜单/权限/键盘用例），Web类型检查、5个变更TypeScript文件lint、生产构建通过；Chrome会话导航1项通过，覆盖分页、改名、归档/恢复、草稿、前进后退、迟到响应和图片设置授权。E2E仅用专用测试库和独立43400/43401端口。

实际43301试用环境只读验证：桌面1512×982及手机390×844，两个设置均默认收起，重命名预填、取消、Escape及菜单/面板位置通过；0个脚本错误、0个会话/图片政策修改、未调用模型。截图及摘要在outputs/workbench-ui-20261028/。试用Web生产构建已更新，浏览器刷新即可看到。
