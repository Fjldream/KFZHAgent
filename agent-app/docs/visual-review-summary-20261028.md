# 识别摘要与批量审核

用户同意先减少识别后的确认负担：批量保留常规区域，只处理例外，免填重复说明。当前试用入口仍为http://127.0.0.1:43301，刷新即可使用新界面；本次改动不要求重新识图或重签旧Run。

| Before | After | Why |
| --- | --- | --- |
| 几十个文字/布局逐项选择和输入说明 | 一个“保留常规内容”按钮，按原区域逐条记录确认 | 减少重复输入，保留原有记录与校验 |
| 表格/图表散落在长列表中 | 按类型集中展示，明确保留或省略，可撤销 | 保留重要差异，不默认丢掉内容 |
| 原生能力名、pending-verification及识别备注常驻 | 默认显示摘要，技术详情/备注按需展开 | 先看到需要决定的事项 |
| 数据/交互要求可能混在长列表里 | 只读数据快照值、本地点击反馈直接显示在摘要 | 批量确认前仍能看到实际要求 |

常规批量仅包括有匹配组件且不属于表格/图表/表单的区域。已验证控件保持原状态；有匹配但未验证的控件仍为未验证，不能将用户批量确认当作运行态验证报告。复杂类型即使已有未验证候选，也单独处理。映射缺失不能通过批量操作跳过。

默认只展示常规汇总与少量例外卡。点击保留不会立即调用模型，最后点击“确认识别并生成蓝图”才提交原合同中的逐区域acceptedDifferences；蓝图生成后仍单独确认。确认说明使用描述该批量操作的固定文本，不编造业务原因；不支持的区域不会自动省略或切换到尚未实现的替代控件。

手动改过的处理方式/说明保留，撤销只清除未被继续修改的批量值。新Run/receipt/analysisId/specHash清除旧选择；编辑、忙碌、外发策略禁止、图片读取失败继续阻止提交。图片默认勾选的近期改动保留，租户权限/服务端准入不变。后端生产代码、数据库、模型协议与KF原生服务未改；API源文件的变更仅为浏览器回归适配新展开入口及验证批量确认。
